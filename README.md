# عود — Oud

> رفيق يوم مسلم هادئ على الويب: مواقيت، أذكار، مصحف كامل يعمل دون إنترنت، أحاديث وأدعية بمصادرها، وتتبع استمرارية — **بلا إعلانات، بلا اشتراكات، بلا أن يغادر موقعك جهازك إلا لخدمة المواقيت**.

## المشكلة التي يحلها

تطبيقات العبادة السائدة (Muslim Pro، Athan Pro) عرفت بغزارة الإعلانات، وبيع الأوفلاين ضمن الاشتراك، ومشاركة الموقع لأطراف ثالثة. «عود» يقدّم الحلقة اليومية نفسها — بل أنقى: أوفلاين كامل مجاني، خصوصية مصارح بها، وخفّة (PWA بعدة ميجابايتات لا 300+).

## أهم الميزات

- **مواقيت الصلاة** من Aladhan باختيار المدينة أو الموقع، مع طبقات احتياط ثلاث (ذاكرة 6 ساعات → آخر قيمة محفوظة → جداول مدمجة).
- **أذكار موقوتة** (صباح/مساء/نوم/بعد الصلاة/الهمّ) بمصادرها وتكرارها، وتسجيل الإنجاز.
- **المصحف كاملًا أوفلاين**: تنزيل مرة واحدة (IndexedDB) + نسخة مدمجة داخل التطبيق، قراءة مستمرة آية بآية مع تمرير تلقائي وحفظ الموضح وعلامات مرجعية.
- **أحاديث وأدعية وأبيات** مبحوثة محليًا وبمصادرها ورواة.
- **تتبّع استمرارية**: تسجيل الصلوات (جماعة/في الوقت/متأخرة/فائتة)، إحصاءات 30 يومًا، سلسلة أيام كاملة، أضعف صلاة، وبطاقة «ثباتك» على الرئيسية.
- **إشعارات في وقتها**: جدول تذكيرات (مواقيت/وارد/نوم/جمعة/رمضان) مع نافذة إطلاق 10 دقائق وإزالة تكرار يومية.
- **PWA كاملة**: تثبيت، عمل دون اتصال، تحديث تلقائي، اختصارات.
- **محفوظات موحّدة**: مزامنة خادمية + مرآة محلية فورية مع دمج ذكي عند العودة.
- **تصدير البيانات** JSON من الإعدادات.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript + Vite |
| التنسيق | Tailwind CSS v4 + shadcn/ui + هوية glass مخصصة |
| الخادم وقاعدة البيانات | Convex (queries/mutations مفهرسة + Convex Auth) |
| المصادقة | Email OTP + Anonymous (Convex Auth) |
| الحركة | Framer Motion |
| التغليف | Bun (حزم + اختبارات) |

## البنية المعمارية

```
src/
├── convex/            الخادم: planner.ts (منطق البيانات كلّه المحمي)، auth/، schema.ts
├── components/app/    شاشات التطبيق (HomeView، QuranView، PrayerView، ...)
├── components/ui/     shadcn/ui
├── hooks/             الحالة: مواقيت، تفضيلات، محفوظات، تذكيرات، تنبيهات، ساعة مشتركة
├── lib/               منطق خالص قابل للاختبار: time، hijri، prayers، quran-store، notify، pwa
├── data/              المحتوى الثابت المدمج (مصحف، أحاديث، أذكار، أدعية، قصص، مناسبات)
└── pages/             Landing، Auth، Dashboard (المحمي)، Onboarding
tests/                 اختبارات bun للطبقة الخالصة
public/                sw.js + manifest + أيقونات
```

مبادئ معمارية: كل mutation محمي بـ `requireUserId` وvalidators مغلقة على حدود الخادم؛ سلسلة تخزين المصحف (ذاكرة → IndexedDB → مدمج → شبكة)؛ مؤقّتات مشتركة bucketed لتقليل إعادة التصيير؛ استعلامات نطاق مفهرسة لا حلقات يومية.

## التشغيل والتطوير

```bash
bun install          # تثبيت
bun dev              # بيئة تطوير (منصة Freebuff تدير الخدمات)
bun test             # 48 اختبار وحدة (bun test أصلي)
bun run typecheck    # tsc -b --noEmit
bun run build        # إنتاج إصدار النشر إلى dist/
bun run package:zip  # توليد /releases/oud-project.zip + نسخة الإنتاج
```

متغيرات البيئة تُدار من لوحة المفاتيح الخاصة بالمنصة (لا تُكتب في المستودع). راجع `.env.example`-equivalent في الوثائق داخل `integrations.md`.

## بناء APK

هذا تطبيق **PWA** وليس مشروع Android أصيل. لا توجد toolchain أندرويد في بيئة التطوير هذه، فلم يُنتج APK (لا ملفات وهمية). للتغليف كتطبيق أندرويد: TWA عبر [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) (`npx @bubblewrap/cli init --manifest https://<domain>/manifest.webmanifest`) أو Capacitor — بعد نشر `dist/` على نطاق HTTPS ثابت.

## ملاحظات أمان

- كل استعلامات/طفرات بيانات المستخدم محمية بالمصادقة والتحقق من الملكية على الخادم.
- لا أسرار في المستودع: `.gitignore` يحجب `.env*` والمفاتيح وkeystores، وسكربت التغليف يعمّي أي مفتاح منصة قبل الشحن ويُعيد فحص الحزم آليًا.
- موقع المستخدم يُستخدم لحساب المواقيت فقط ولا يُرسل لأي طرف آخر (موثق داخل الإعدادات).
- ملف قالب المنصة `src/convex/auth/emailOtp.ts` ملك لبيئة Freebuff ويُدار مركزيًا — يُنصح بنقل مفتاحه إلى env عند توفر الدعم (انظر FINAL_AUDIT §5).
